🚖 Uber Trip Analysis

📌 Project Overview

This project analyzes Uber ride request data using Excel, SQL, and Python to identify demand patterns, trip status trends, and operational challenges. The goal is to generate business insights and recommend strategies to improve trip completion rates and customer satisfaction.

---

🎯 Business Objectives

- Identify reasons for unsuccessful ride requests.
- Analyze peak demand hours and customer request patterns.
- Compare demand across Airport and City pickup points.
- Improve trip completion rates by reducing cancellations and unavailable cars.
- Provide data-driven business recommendations.

---

🛠️ Tools Used

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Git & GitHub

---

📈 Key Insights

- Total Requests: 6,745
- Trip Completed: 42%
- No Cars Available: 39%
- Cancelled Trips: 19%
- Peak demand occurs during 5 AM–10 AM and 5 PM–9 PM.
- Better driver allocation can improve trip completion rates.

---

💡 Recommendations

- Increase driver availability during peak hours.
- Optimize driver allocation between Airport and City.
- Reduce trip cancellations through better driver response.
- Use historical data for demand forecasting.
